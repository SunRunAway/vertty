# Vhostty 远程客户端 MVP

状态：产品范围已确认，尚未实现；多端接管规则待确认。更新日期：2026 年 10 月 14 日。

用户通过 iPhone 或另一台 Mac 上的 Vhostty，连接自己的电脑，查看项目、会话和历史，继续操作电脑上的 Claude Code / Codex。会话和任务实际运行在被连接的电脑上。

本文规定产品范围和用户行为，不规定技术实现。

## 平台与连接

- iPhone 端只能作为远程客户端，不提供本地会话模式。
- 桌面端支持本地使用，也支持作为远程客户端连接另一台电脑。本地使用保留现有功能；本文的功能裁剪只适用于远程模式。
- 远程客户端要求用户输入服务 URL。客户端与服务端之间的安全联通由用户自行保证。
- MVP 不做账号系统、配对码或访问凭证。
- 界面清楚区分当前是本地还是远程，以及正在连接的电脑，避免误操作另一台电脑的会话。
- 远程连接不迁移项目或执行环境。代码、工具和会话进程仍在被连接的电脑上。

## 产品形式

项目列表、会话卡片、会话历史等内容按设备尺寸展示。进入会话后显示并操作该会话的终端，沿用 Claude Code / Codex 原有的输入、菜单和交互确认。

MVP 不另做聊天式会话界面，不把 agent 的终端交互重新设计成消息卡片或业务按钮。

## 功能范围

| 功能 | 远程端 MVP 行为 |
| --- | --- |
| Projects | 只读浏览被连接电脑已有的项目，不提供项目管理操作 |
| Session cards | 保留会话卡片，支持查看、新建、resume 和关闭 session |
| Live status | 保留，展示被连接电脑上的实际会话状态 |
| Notifications | 保留客户端连接期间的通知 |
| Session history | 保留，可浏览并 resume 历史会话 |
| Bottom shell | 不提供 |
| Closed-lid sleep protection | 完全不参与，不读取或展示状态，不提供设置或初始化弹框 |
| Scheduled tasks | 完全不参与，不读取或展示状态，不提供管理页面或操作 |

除终端内的正常输入外，远程界面改变会话的操作只有三个：**新建 session、resume session、关闭 session**。不增加项目编辑、排序、会话重命名、定时任务管理等操作。

浏览、选择会话以及连接电脑属于使用客户端的必要操作，不增加被连接电脑的管理能力。

## 项目与会话

### 项目只读

远程端展示被连接电脑的项目。添加、移除、编辑项目及修改项目设置均在本地端完成；远程端不提供这些入口。

### 新建 session

用户在已有项目下新建 Claude Code 或 Codex 会话。默认 agent 沿用该项目在本地端的设置，远程端不修改默认设置。

创建成功后显示对应卡片并可进入终端。其他连接到这台电脑的客户端同步看到该会话。

同一次新建操作不能因网络中断或重试产生多个会话；用户再次明确执行新建，则创建另一个会话。

### 打开运行中的 session

点击已经运行的卡片，进入同一个会话，不另外启动一个副本。手机与桌面操作的是被连接电脑上的同一个会话。

### Resume session

从 Session history 恢复原会话，保留原有上下文。若该会话已经打开，则进入已有卡片，不再重复启动。

恢复失败时显示失败，不擅自替换成新会话。

### 关闭 session

**点击卡片上的“关闭 session”，关闭被连接电脑上的对应 session，行为与本地端关闭一致。** 沿用本地关闭所需的确认规则，远程用户能够在当前客户端完成确认。其他客户端同步更新，历史仍按现有行为保留并可 resume。

关闭只作用于用户选中的 session，不影响其他会话。

## 连接中断与恢复

本节描述连接生命周期，与点击卡片上的“关闭 session”是独立行为。

- 远程客户端断网、退出 App 或主动断开连接，不等于关闭 session，不因客户端离开而结束电脑上的会话。
- 连接中断时明确显示不可用状态，不把旧的会话状态显示成仍在实时更新。
- 重新连接后恢复项目、卡片、历史和实际运行状态，并能够继续查看、操作原会话。
- 电脑上的任务是否能够继续，取决于电脑和本地端的实际运行情况；远程端不负责唤醒电脑或改变休眠设置。

## 终端尺寸与多端使用

手机与电脑屏幕尺寸不同，同一会话的终端布局需要统一协调。MVP 不承诺两端同时按各自宽度独立排版并自由输入。

待确认的交互建议：

- 区分“查看”和“接管”：查看不改变会话的终端尺寸，手机可缩放或横向查看。
- 接管后按当前设备的可用空间调整终端，其他设备看到同一布局。
- 同一会话同一时间只有一个操作端，其他端可查看；通过明确操作切换接管，避免抢输入或反复改变尺寸。

以上是讨论中的建议，尚未作为已确认的 MVP 规则；实现前需确定具体交互。

## Live status、历史与通知

Live status 和 Session history 以被连接电脑的实际信息为准。远程客户端保留查看运行状态、浏览历史和恢复会话的能力。

通知保留已有会话通知的含义，不增加定时任务通知中心或额外管理功能。MVP 只覆盖客户端连接期间的通知，**不实现 iPhone 退到后台或锁屏后的可靠推送**。

## 远程端完全不参与的功能

### Closed-lid sleep protection

远程端不读取状态、不展示状态、不提供设置、不触发或承接本地初始化弹框。相关行为完全依赖本地端已有的设置和运行情况。远程端对此功能无感。

### Scheduled tasks

远程端不读取任务状态、不展示任务列表、详情或运行记录，不提供创建、修改、启停、删除或立即运行入口，也不承接相关管理弹框。

即使用户通过 skill 创建或操作了定时任务，远程端也不增加处理流程或管理能力。定时任务仍按本地端既有规则运行，远程端对此功能无感。本范围不改变 [定时任务产品设计](schedule-product.md) 中的本地行为。

### Bottom shell

远程端不显示底部 shell，不提供打开入口或对应快捷操作。

## MVP 验收重点

- iPhone 只提供远程使用；桌面能本地使用或连接另一台电脑。
- 输入 URL 即可发起连接，不要求账号、配对码或访问凭证；客户端与服务端之间的安全联通由用户自行保证。
- 远程端能浏览已有项目，但没有项目管理入口。
- 能新建、resume 和关闭 session；打开已运行会话不会新建副本。
- 新建操作重试不重复创建；重复 resume 已打开会话不重复启动。
- 关闭卡片与本地关闭行为一致，确认可在远程端完成，其他端同步更新。
- 断开连接与关闭 session 分开处理；重连后能继续进入原会话。
- Live status、Session history 和连接期间的 notifications 保留。
- 不实现 iPhone 后台或锁屏可靠推送。
- 远程端没有 Bottom shell、项目管理、休眠保护和定时任务管理入口。
- 休眠保护与定时任务的状态、设置、初始化或管理弹框不会进入远程端；skill 操作也不改变这一范围。
